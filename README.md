This is a desktop app develop for self learning purpose. 
This local desktop app build using electron forge withe React plugin and better sqlite3
It is built on linux mint OS 

this app is a simple journal app which can record event and attach with an image and store locally in the computer.

This app allow user to store date, attendant and particular and attach one image to save as a record.


it allow searching of specific records and view in detail.

it also allow user to generate a pdf journal report according to specific criteria.
